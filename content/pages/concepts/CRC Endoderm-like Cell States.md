# CRC Endoderm-like Cell States

대장암(CRC)에서 발견되는 비표준(non-canonical) 악성 세포 상태. MSS/KRAS 돌연변이 CRC에 농축되어 있으며 **oncofetal plasticity** 특성을 보임.

---

## State 20: Hybrid-Endoderm-like 1

| 항목 | 내용 |
|------|------|
| 농축 조건 | MSS CRC (OR=9.5, adj. p<0.05) |
| 핵심 TF | HAND1, ISL1, NR6A1 (발생 패터닝), SMAD1 (BMP signaling), HNF1A, FOXA3 (간세포/내배엽 정체성) |
| 차별 발현 유전자 | ASCL2 (WNT), EREG, AREG (EGFR signaling) |
| 면역 상호작용 | Exhausted T cell (Tex)과 **CXCL14-CXCR4** 축 → 면역억제 미세환경 시사 |
| 예후 | CXCL14 고발현 → stage III/IV 불량 예후와 연관 |

## State 21: Hybrid-Endoderm-like 2

| 항목 | 내용 |
|------|------|
| 농축 조건 | MSS + KRAS 돌연변이 CRC (OR=106.6, adj. p<0.05) |
| 핵심 TF | TCF4 (WNT), GATA6, HNF4A, FOXI1 (초기 발생) |
| 차별 발현 유전자 | SOX4, MYC, PROX1, ASCL2, **MEX3A** (drug-tolerant persister 마커) |
| 특징 | Drug-tolerant persister 세포 특성 보유 가능성 |

---

## Oncofetal Plasticity

- 두 상태 모두 정상 결장 또는 표준 CRC 마커에 맞지 않는 "hybrid" 성격
- 간세포/내배엽 계통 TF(HNF1A, FOXA3, HNF4A) 활성화 → 발생 경로 재활성화
- 환자 유래 오르가노이드에서 재현 확인

---

## MAPK 억제와의 관계

- MAPK inhibition → 증식 표현형 이탈 → **Endoderm-like 상태로 수렴**
- Tahoe-100M perturbation atlas를 통해 확인
- 치료 적응(therapy adaptation)의 핵심 경로일 가능성

---

## 임상적 의의

- MSS CRC는 면역관문 억제제에 잘 반응하지 않음 → endoderm-like 상태가 면역억제 미세환경 형성에 기여할 수 있음
- MEX3A 발현 → 약물 내성 메커니즘의 잠재적 표적
- Cell state-directed therapy의 개입 지점
